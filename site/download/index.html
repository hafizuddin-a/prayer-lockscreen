Prayer Live Wallpaper

Prayer times on your Android lock screen.

Download the app Free. No ads. Needs Android 14 or newer. About 4 MB.

How to install

  1. Tap Download the app. If your browser says the file "can harm your device", tap Download anyway. It says that about any app that does not come from Google Play.
  2. Open the file when it finishes. If Android says it cannot install apps from this source, tap Settings, switch on Allow from this source, then go back.
  3. If Google Play Protect says App scan recommended, tap Scan app. When it says the app looks safe, tap Install.
  4. Tap Open. Setup takes about a minute.

Already have the app? Download it again and install it the same way. It goes over the old copy and keeps your settings.

Updates

The app looks for a new version once a day. When there is one, an Update button shows on its first screen. Tap it and follow Android's prompt. To stop the daily check, switch off Keep the app up to date under About.

Is it safe?

  • The app collects nothing: no account, no ads, no tracking. Read the privacy policy.
  • The code is open, so anyone can read it. See it on GitHub.
  • An update only installs if it is signed with the same key as the app you already have, so nobody else can swap it.
  • The warnings above are Android's usual ones for apps from outside Google Play.
